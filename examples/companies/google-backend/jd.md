# Software Engineer III, Backend | Google | Bengaluru

## About the team
Our team builds the backend services behind payments in Google products. We run large distributed systems that handle millions of requests a day, and we care about reliability, clean code and good design.

## What you'll do
- Design, build and run backend services in Java or Go that scale to millions of users.
- Build event-driven pipelines with Pub/Sub or Kafka.
- Deploy and operate services on Kubernetes.
- Define service APIs with gRPC and Protocol Buffers.
- Write unit and integration tests; keep test coverage high.
- Take part in on-call, debug production issues and improve reliability.
- Review code and write design docs.

## Minimum qualifications
- Bachelor's degree in Computer Science or equivalent practical experience.
- 2 years of experience in software development in Java, Go or C++.
- Experience with distributed systems and REST or gRPC APIs.
- Experience with SQL or NoSQL databases.

## Preferred qualifications
- Experience with Kubernetes and containers.
- Experience with messaging systems (Pub/Sub, Kafka, RabbitMQ).
- Experience with caching (Redis, Memcached).
- Experience with on-call and production debugging.
- Strong testing habits (JUnit, integration tests).
